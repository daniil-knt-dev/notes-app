# 🔒 Notes App

Простой менеджер заметок на Python с защитой паролем и сохранением в JSON.

### ✨ Основные функции:
*   **Авторизация:** Вход в приложение только по паролю.
*   **Управление заметками:** Добавление, просмотр и удаление.
*   **Категории:** Каждой заметке можно назначить свою категорию.
*   **Безопасность:** Возможность смены пароля внутри приложения.
*   **Сохранение:** Все данные хранятся в файле `data.json`.

### 🚀 Как запустить:
1. Убедитесь, что у вас установлен Python 3.8+.
2. Скачайте `main.py`.
3. Запустите через терминал: `python main.py`
4. Пароль по умолчанию (если файла нет): **123**
